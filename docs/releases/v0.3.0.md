# Retro Trans 0.3.0

This release adds CHD disc patching and the Z3 save converter to the compact
Windows app. The tabs are now **Automatic**, **Apply xdelta**, and **Z3 saves**;
the Create xdelta tab has been removed.

## Downloads

- **Retro-Trans.exe:** standalone Windows x64 app. No Python or separate patch
  tools need to be installed.
- **Retro-Trans-Windows.zip:** the same EXE, README, and third-party notices.
- **UPDATE.json:** integrity metadata used by the app's automatic updater.

Existing installations check for the update at startup and install a verified
download on the next launch. Settings and caches are preserved.

## CHD support

Open a supported CHD in Automatic or Apply xdelta. CHD inputs default to CHD
output; choose **Original format** to save the patched ISO/BIN instead. The app
extracts the disc, patches it, and verifies the result. CHD output is extracted
again and compared with the verified patched disc before saving. Originals are
preserved, existing outputs are refused, and temporary images are cleaned up.

- Supports standalone CHD v5 DVDs and single data-track CDs in MODE1/2048,
  MODE1/2352, and MODE2/2352, without gaps or subchannels.
- Multi-track/audio CDs, GD-ROM, parent-dependent CHDs, and other layouts remain
  unsupported. CHD conversion does not make an unsupported game patchable.
- Known DVD hashes provide quick identification; extracted bytes are verified
  before patching. CD and SHA-256-only recognition can require extraction.
- Manual xdelta can also patch compressed CHD bytes directly: disable
  **Unpack CHD input before patching** and use **Original format**.
- The pinned chdman engine is bundled for offline use. CHD operations require an
  x86-64-v2-capable CPU and additional disk space for temporary disc images.

## Z3 saves

Convert decrypted **Jigoku-hen** saves between RPCS3 (NPJB00520) and Vita3K
(PCSG00264), in either direction or both. Select both save profiles, close the
emulators, then use **Check saves** and **Convert saves**. Output includes
backups, verified ZIPs, slot mappings, and import instructions.

This is an offline emulator-save converter. It does not decrypt, resign, or
install physical-console saves, and does not support Tengoku-hen. Converted
saves still need an in-game load/save/reload check.

## Validation

Automated tests cover synthetic CHD extraction/patch/compression round trips,
upgrade chains, save conversion in both directions, cancellation, corrupted
inputs, existing-output preservation, offline operation, and display scaling.
Release checks also exercise the packaged app's offline startup and a real
next-launch update with isolated test installations. These are file-format and
application checks, not game-specific playtesting.
