Retro Trans 0.3.1 supports maintainer-withdrawn patches.

- Discontinued patches no longer appear in automatic selection or upgrade routes.
- Historical hashes and binary identities remain in the catalog, so withdrawal cannot silently replace patch bytes or change a known disc identity.
- Existing cached catalogs can refresh to the new catalog without rejecting an explicitly recorded withdrawal.

ACE3 now offers only its English prologue edition. Update to this version before refreshing an older catalog containing its discontinued non-movie patches.

Download **Retro-Trans.exe** or the Windows ZIP. Existing installations can use the app updater.
