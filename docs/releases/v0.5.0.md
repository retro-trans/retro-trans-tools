# Retro Trans 0.5.0

CHD inputs now ask before extraction, keep the extracted disc, and reuse it when
patching. This release also adds experimental SRW MX save conversion and clearer
PS3 installation reminders.

## Patching improvements

- The main window title shows the application version.
- CHD scanning lists candidates without unpacking them. Selecting a CHD asks
  before creating a new `<game>-unpacked` child folder beside it. The app then
  selects the extracted ISO/BIN, so clicking Patch does not unpack the source
  again. Existing folders and original files are preserved; interrupted
  extractions are cleaned up.
- CHD output remains the default after extraction. The newly compressed output
  still receives a separate verification round trip before it is saved.
- PS3 patches warn users to remove the related old installation data before
  playing, while keeping saved games, game images, and other games. The tool
  never deletes console or emulator installation data.
- Includes the latest verified catalog, with reviewed multi-file disc metadata
  for Marionette Handler 2 and preserved release withdrawals.

## Experimental SRW MX save conversion

The **Save conversion** tab can create PS2 ↔ PSP manual-save test candidates for
the reviewed early Hugo/Cerberus intermission: two completed maps in the PS2
English PSP-stage port and MX Portable English 0.4.9. The reviewed PS2 output
profile is local build 0.1.18. Other checkpoints, stock PS2 campaigns, system
saves, and battle saves are not supported.

- Preserves mapped party records, progression, funds, and all favorite-series
  choices, including the PS2 three-favorite selection.
- One **PSP difficulty on PS2** checkbox replaces the difficulty dropdown.
  PSP → PS2 defaults to checked; untick for PS2 Original. For PS2 → PSP,
  **Check saves** reads and displays the source setting; PSP output always
  uses PSP difficulty. Existing funds are not rescaled.
- Game-file paths and slot selection are in an expandable section.
- Creates PS2 PSU/extracted saves or PPSSPP plaintext saves, with original
  backups, verified ZIPs, and a conversion report. Never installs into a live
  memory card or overwrites existing output.
- Encrypted PSP input requires the user's reviewed PSP ISO/BOOT.BIN and
  PPSSPP 1.20.4 Windows x64 executable. No game files or keys are bundled.

One converted PSP candidate was reported loading and playing in PPSSPP.
**PS2 loading and a full save/reload cycle remain unverified.** Use a separate
test card or emulator profile and retain original saves. This is not a general
whole-campaign converter or a physical-PSP save package. Z3 save conversion
remains available.

## Downloads

- **Retro-Trans.exe:** standalone Windows x64 app; no Python installation needed.
- **Retro-Trans-Windows.zip:** the same EXE, README, and third-party notices.
- **UPDATE.json:** executable size and SHA-256 for verified automatic updates.

Existing installations check for updates at startup and install staged updates
on the next launch, preserving settings and caches. Catalog updates remain
independent of application releases.
