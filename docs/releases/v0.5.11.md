# Retro Trans 0.5.11

Create a translated Vita3K PKG directly from **Automatic**. The app downloads
the translation ZIP for your original game; you supply the game and its license.

## Vita PKG in Automatic

1. Browse to your original Vita `.pkg`, or select its folder with **Folder…**.
2. Select the matching local NoNpDrm `work.bin` or `.rif` under **Matching license**.
3. Choose a new **Translated PKG** filename and click **Patch**.
4. Install the completed PKG in Vita3K using the same matching license.

The app identifies the title, matches the complete original package hash to a
published release profile and downloads its newest compatible translation ZIP.
It checks the translation assets, rebuilds encrypted PFS and verifies every
installed game file in an isolated Vita3K filesystem before saving the output.
Your original package, license, existing emulator installation and saves are preserved.
Browsing and scanning do not download patches.

Public translation releases need no GitHub sign-in. Private releases require
access; the app can use an existing GitHub CLI sign-in or `GH_TOKEN`/`GITHUB_TOKEN`.
Credentials stay in memory and are stripped from asset redirects. Game packages
and licenses are never downloaded or uploaded.

Use Windows x64, internet access and at least **6 GB free** on the output drive.
The PKG engine supports the formats declared by compatible release profiles;
other game editions and encryption formats are rejected. The output is intended
for Vita3K and is not a verified physical-Vita installation method.

## Other changes

- Keep **Vita → Vita3K PKG** for a local ZIP/JSON override and **Hardware rePatch**
  for console overlays. New supported games use release profiles without new UI options.
- Retry transient Windows file locks during Vita file verification and temporary
  workspace cleanup. Preserve the original error if cleanup also fails.
- Include local diagnostic logs and **Open logs**; raw keys, license contents,
  private paths and native installer output are excluded.
- Retain existing xdelta, multi-file, CHD and save-conversion workflows.

## Verification

The 247-test Windows suite passed with four platform-specific skips. Standalone
startup, crypto/disc checks and a real next-launch update passed. The actual
Automatic UI worker downloaded Cross Ange's private translation ZIP without a
local patch selection and verified all 48 installed files; its output matched
the independently verified 0.1.13 package. A packaged conversion also passed
while a real Windows handle temporarily blocked CPK cleanup.

These checks verify package conversion and installation; full game playtesting
and physical-console testing remain pending. See the
[validation record](https://github.com/retro-trans/retro-trans-tools/blob/main/docs/releases/v0.5.11-validation.json)
and [Vita instructions](https://github.com/retro-trans/retro-trans-tools/blob/main/docs/VITA_PKG.md).

## Downloads

- **Retro-Trans.exe:** standalone Windows x64 app; no Python installation needed.
- **Retro-Trans-Windows.zip:** the same EXE with README and dependency notices.
- **UPDATE.json:** verified automatic-update metadata for the executable.

Existing installations check for updates at startup and apply a staged update
on the next launch. This release provides Windows binaries. Older Mac 0.5.6
test builds remain attached to the 0.5.4 release; no new Mac build is included.
