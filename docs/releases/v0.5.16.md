# Retro Trans 0.5.16

### What's included

- **Vita PKGs in Automatic:** choose your original PKG, matching local **work.bin / compatible NoNpDrm .rif**, and a new output filename. The app downloads small translation patches and rebuilds an English PKG locally for Vita3K.
- **Generic hardware rePatch:** discover the matching game's translation automatically or select a local patch ZIP. Added credits/font attribution are verified; asset-only overlays preserve the original executable.
- Safe cleanup and retries for transient Windows file locks.
- Existing manual CPK/xdelta patching, CHD handling and save conversion.

### Using Vita PKG Automatic

1. Select the original PKG and that exact game's matching license.
2. Choose a new output PKG and click **Patch**.
3. Install the result in Vita3K using **the same license**.

Cross Ange's translation download is about **5.4 MB**. Allow **6 GB free**; first use also downloads the official Vita3K runtime. Your game/license stay local. Public releases need no GitHub sign-in; private profiles use existing GitHub CLI access. GitHub's anonymous API request limits still apply.

See [Vita3K instructions](https://github.com/retro-trans/retro-trans-tools/blob/main/docs/VITA_PKG.md), [hardware rePatch](https://github.com/retro-trans/retro-trans-tools/blob/main/docs/VITA_REPATCH.md) and [getting work.bin](https://github.com/retro-trans/retro-trans-tools/blob/main/docs/VITA_WORK_BIN.md).

### Validation

The suite ran **257 tests**, with four platform skips. Frozen Automatic and the actual UI reproduced Cross Ange's English PKG; each isolated Vita3K installation verified all **48 game files**. Full gameplay and physical-Vita compatibility remain unverified. PKG rebuilding is Windows-only.

### Downloads

- **Retro-Trans.exe:** standalone Windows x64 app; no Python installation needed.
- **Retro-Trans-Windows.zip:** the same app, README and dependency licenses.
- **UPDATE.json:** verified automatic-update metadata.
- **SHA256SUMS.txt** and **RELEASE-VALIDATION.json:** checksums and validation details.

Existing Windows apps can download the update and install it on their next launch. Older Mac test builds remain separate; this release contains Windows files.
