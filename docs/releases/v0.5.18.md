Fixes the About dialog showing an old update version even though a newer app is running.

- About always displays the running app version, matching the window title.
- Update status refreshes when About opens. Success messages for another app version no longer appear as current, including after future upgrades or manual EXE replacement.
- A successful update check clears an earlier check error. Current download notices and installation failures remain visible.
- Includes the latest verified patch catalog and the catalog validation improvements made since 0.5.17.

Download **Retro-Trans-Windows.zip** for the app and required notices, or **Retro-Trans.exe** to update an existing installation. Existing installations can also download this update automatically and install it on the next launch.

Validation: the 280-test suite passes with four platform-specific skips. The standalone Windows startup and next-launch update checks pass, including backup and settings preservation.
