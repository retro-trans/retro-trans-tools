# Retro Trans 0.5.19 — Dreamcast DCP support for Windows

Download **Retro-Trans.exe** and run it on 64-bit Windows 10/11, or use
**Retro-Trans-Windows.zip**, which also includes instructions, licenses and the
DCP engine's corresponding source. No Python or .NET installation is required.
Existing Windows installations can download this update automatically and
install it at their next launch.

## New DCP tab

- Apply a local `.dcp` package to a Dreamcast GDI, CUE or CHD, including full
  translations and upgrades from the patch's required previous version.
- Save a new GDI, CUE/BIN or CHD folder. Originals and existing output folders
  are preserved. Allow 12 GB of free temporary space beside input and output.
- CHD extraction asks first, keeps the completed extracted disc beside its
  source and selects it for reuse; click **Apply DCP** after extraction.
- The pinned Universal Dreamcast Patcher 2.1.8 engine is bundled for offline
  use. Rebuilt output is re-extracted and its CD audio is checked. Compatible
  Retro Trans metadata additionally verifies every game file and boot-code
  invariants. Generic DCPs retain xdelta and readability checks without claiming
  a publisher-supplied whole-output hash.

Automatic catalog patching, manual xdelta, save conversion, Vita PKG/rePatch and
the version/update-status fixes remain included, with the current verified
catalog. DCP packages are selected locally in their own tab.

## Validation and limits

Local Windows validation passes 293 tests with four platform-specific skips,
standalone engine/startup checks and an isolated next-launch update. The release
workflow repeats these checks before publication. Update checks cover verified
replacement, backup and settings preservation. Local Rayblade full/upgrade and GDI/CUE/CHD
checks are recorded in [the DCP validation report](https://github.com/retro-trans/retro-trans-tools/blob/v0.5.19/docs/dcp-validation.json).
Rebuilt track layout can differ from raw-track xdelta output even when all game
files match. Physical Dreamcast/GDEMU and gameplay progression remain unverified.

See [DCP instructions](https://github.com/retro-trans/retro-trans-tools/blob/v0.5.19/docs/DCP.md).

This release adds Windows downloads. **Mac 0.5.18** (Apple Silicon and Intel) and
**Android 0.1.0-test1** remain available on the
[0.5.18 release](https://github.com/retro-trans/retro-trans-tools/releases/tag/v0.5.18);
those builds do not include DCP.
