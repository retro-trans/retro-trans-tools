# Retro Trans 0.5.2

Adds a physical-Vita rePatch workflow for SRW Z3 Jigoku-hen:
**original PKG + matching work.bin → Create rePatch → copy to Vita**.

## Vita rePatch

- Open **Vita rePatch**, select the original PCSG00264 v01.00 PKG and its
  matching NoNpDrm `work.bin`, choose a new output folder, and click
  **Create rePatch**. No decrypted-folder preparation, Python, terminal
  commands, firmware download, or configured Vita3K installation is needed.
- The app downloads the official Vita3K Windows tool directly from its publisher
  and runs package conversion inside an isolated temporary portable folder.
  It does not use your existing emulator setup, installed games, or saves.
- Requires an x64 Windows PC, internet, **6 GB free** on the output drive, and
  the matching Vita patch profile. Uses the optional profile/deltas from
  [SRW Z3 v0.9.0](https://github.com/retro-trans/SRW-Z3/releases/tag/v0.9.0);
  a reviewed local `VITA-REPATCH.json` and its bare deltas can also be selected.
- Verifies the original package, matching license identity, downloaded tool,
  every patch, and every resulting file. Existing output is never overwritten.
  Cancellation/failure cleans up temporary work without publishing a partial
  overlay. The original PKG and work.bin are unchanged and never uploaded.
- Copy the generated `rePatch/PCSG00264` to `ux0:rePatch/PCSG00264` with
  VitaShell after closing the game and backing up saves/any older overlay.
  Do not merge old mods or overwrite the installed game, updates, or savedata.
  Compatible rePatch and your installed original game are required.

The output includes sanitized executable permissions for `self_auth.bin`;
no personal auth dump is needed. The encoded license is passed locally to the
official tool, so it can be visible briefly to local process-inspection tools;
Retro Trans does not log it. See [Vita instructions](https://github.com/retro-trans/retro-trans-tools/blob/main/docs/VITA_REPATCH.md)
for obtaining your own work.bin, privacy details, and disabling the overlay.

The complete PKG-to-overlay test matched all **154 payloads** against the
verified test18 build. **Physical boot, gameplay, and save/reload remain
unverified for this integration.** The Vita staff roll and ending teaser still
use Japanese. This is not a Vita3K installer or a PKG-to-PKG xdelta patch.

## Existing workflows

- Automatic PS3/disc patching and existing cached-catalog upgrade routes remain
  unchanged. Vita rePatch is a dedicated tab, not a new disc-catalog identity.
- CHD consent/reuse, PS3 installation-data reminders, Z3 save conversion and
  experimental MX save conversion are retained. Saved games are never removed.
- The main window continues to show the application version. All four tabs
  pass layout checks at normal, 150% and 200% scaling.

## Downloads

- **Retro-Trans.exe:** standalone Windows x64 app; no Python installation needed.
- **Retro-Trans-Windows.zip:** the same EXE, README, and third-party notices.
- **UPDATE.json:** executable size and SHA-256 for verified automatic updates.

Existing installations check for updates at startup and install staged updates
on the next launch, preserving settings and caches. Catalog updates remain
independent of application releases. No game package or license is bundled.
