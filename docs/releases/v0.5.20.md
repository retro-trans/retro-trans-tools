# Retro Trans 0.5.20 — Automatic Dreamcast DCP patches

Download **Retro-Trans-Windows.zip**, extract it and run **Retro-Trans.exe**.
The ZIP includes the required runtime notices and DCP engine source. No Python
or .NET installation is required. Existing Windows installations can update on
their next launch. Mac/Android downloads are unchanged and do not include DCP.

## Black/Matrix AD in Automatic

- Recognizes both original Japanese Disc 1 and Disc 2 CUE/BIN sets. Browse to the
  matching CUE with all companion tracks together, or select its folder.
- Offers v0.9.0 as an explicitly labelled experimental DCP release. The matching
  DCP is downloaded when you click Patch; no manual patch selection is needed.
- Save a new GDI, CUE/BIN or CHD folder. Every original track is rechecked,
  downloads are size/SHA-256 verified, and embedded package metadata must agree
  with the catalog. All rebuilt game files, boot invariants and CD audio are
  verified before the completed output is saved. Originals are never overwritten.
- Uses the existing published DCP bytes, not standalone track-level xdelta.

Initial automatic recognition uses exact original raw-track fingerprints.
Alternate GDI layouts and CHD inputs can use the separate **DCP** tab. Scanning
never extracts a CHD. Allow at least 12 GB free beside the new output folder.
The earlier binary/xdelta, multi-file, Vita and save-conversion routes remain.

Automatic DCP publisher metadata is independent of standard binary manifests;
catalog refresh downloads and verifies each package and its source/target tree
identities. Existing binary identities and assets are preserved. Older apps
ignore the added DCP records; update to 0.5.20 to use them.

Binary verification is not a physical Dreamcast/GDEMU or full-game playthrough
claim. See the Black/Matrix AD release notes for its remaining limitations.

Local validation: 303 tests with four skips, native Automatic UI checks, both
discs through real Automatic downloads to GDI, both through the packaged EXE to
CUE/BIN, and an isolated next-launch update. The four rebuilt results match the
published game-file/boot identities and preserve CD audio; original disc files
are unchanged. The actual published 0.5.19 EXE also accepts the updated catalog
and retains all 246 binary patch routes. See
[the pre-publication validation record](https://github.com/retro-trans/retro-trans-tools/blob/v0.5.20/docs/builds/v0.5.20-validation.json).
