# Retro Trans 0.5.21 — GameCube and Wii RVZ support

Download **Retro-Trans-Windows.zip**, extract it and run **Retro-Trans.exe**.
The ZIP includes conversion-engine notices and source references. No Python or
.NET installation is needed. RVZ conversion requires **Windows 10 1903 or later,
x64**, and the current [Microsoft Visual C++ v14 x64 runtime](https://aka.ms/vc14/vc_redist.x64.exe).
The converter is bundled; no separate Dolphin installation is required.

## RVZ in Automatic

1. Select your original GameCube or Wii RVZ.
2. Approve extraction into a new child folder beside it. The original RVZ and
   completed ISO are kept; scanning never extracts a disc silently.
3. Select the target release and a new output filename. Choose **RVZ** for
   compressed output, or **Original format** for ISO output.
4. Click **Patch**. The app reuses the extracted ISO, downloads the matching
   patch, and verifies the complete source and output ISO identities.

RVZ output is lossless, without scrubbing. Before saving it, the app extracts it
again and compares the complete ISO SHA-256. Catalog identities and game patches
remain ISO-based, independent of RVZ compression settings. Existing outputs are
refused and originals are preserved. Only games with compatible published patch
routes can be applied automatically; format support does not add a translation.

Allow space beside the source for the retained ISO and on the output drive for
up to three target ISO sizes plus compression overhead and 64 MiB reserve.
Failed or cancelled private work is cleaned up; completed retained extractions
remain available for another attempt. See [RVZ instructions](https://github.com/retro-trans/retro-trans-tools/blob/v0.5.21/docs/RVZ.md).

## Other changes and compatibility

- **Apply xdelta** also supports RVZ input and GameCube/Wii RVZ output. Keep
  **Unpack CHD/RVZ input before patching** checked for ISO-based patches. Raw
  compressed-byte patches remain possible with unpacking disabled.
- Includes the central game library and direct Vita profile discovery already
  developed on main, reducing repeated GitHub discovery requests. Private
  profiles still require authorized local access; no licenses are distributed.
- Existing ISO/CHD, multi-file, Dreamcast DCP, Vita and save-conversion workflows
  remain available. Game patches, original-image hashes and older releases are
  unchanged.
- Existing Windows installations can obtain this update through the next-launch
  updater. After updating, click **Refresh catalog** for newly published games.
- **Mac and Android downloads are unchanged.** This release adds RVZ conversion
  on Windows only. Earlier Mac/Android downloads remain on their existing releases.

## Verification and limits

Pre-publication testing passed **337 tests with four platform skips**, packaged
startup and native engine checks. The packaged app processed a real original
**Tengai Makyou II** RVZ through a live v0.8.0 patch download to English RVZ;
independent extraction matched the complete expected ISO hash. Source
preservation, already-current recognition and overwrite refusal passed.
[Pre-publication evidence](https://github.com/retro-trans/retro-trans-tools/blob/v0.5.21/docs/builds/v0.5.21-rvz-local-validation.json).

The tagged release workflow runs the full suite, packaged health checks and an
isolated next-launch update before publication. Conversion uses official pinned
**DolphinTool 2609a**, with its notices and exact corresponding-source references.
It does not launch the Dolphin game emulator. No game images are included.
Binary and conversion verification do not establish gameplay, physical-console
compatibility or actual memory-card write/restart/reload behavior.

Published-artifact verification: the actual public EXE and ZIP match their publisher SHA-256 digests and each other. The public app passed native health checks and real Tengai Makyou II RVZ input/output with independent full-ISO verification. The updater staged the verified public download from 0.5.20 in an isolated cache; the tagged workflow also passed replacement, startup, backup and settings preservation. [Published verification report](https://github.com/retro-trans/retro-trans-tools/releases/download/v0.5.21/WINDOWS-0.5.21-VALIDATION.json).
