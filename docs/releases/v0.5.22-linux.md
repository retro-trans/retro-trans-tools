# Linux addition to Retro Trans v0.5.22

Download `Retro-Trans-Linux-x86_64-0.5.22.tar.gz` from the existing
[0.5.22 release](https://github.com/retro-trans/retro-trans-tools/releases/tag/v0.5.22).
Extract the entire archive and run `Retro-Trans/Retro-Trans`.

Requires an Ubuntu 24.04-compatible x86-64 desktop, glibc 2.39 or newer,
and X11/XWayland. No Python, .NET, Wine, or separate patch-engine installation
is needed. See [Linux instructions](../LINUX.md) for features and limitations.
Linux app updates are manual; catalogs and the game library refresh automatically.
Vita original-PKG rebuilding and PKG-based hardware rePatch require Windows.
ARM Linux, Steam Deck, and real-game gameplay have not been validated.

The original v0.5.22 tag and all Windows assets are preserved. This Linux addition
was built from source commit `93c5f0c21ad6d44efd2c4986358cb53cfd14fd7b`.

Validation: 367 tests on Linux (10 expected skips) and Windows (5 expected skips),
packaged HTTPS/catalog checks, and offline startup/CHD/RVZ checks as a normal user
in a clean Ubuntu 24.04 container without Python, .NET, or installed patch engines.
The DCP engine starts and verifies its bundled files; save cryptography passes
known-answer checks. These checks do not establish real-game compatibility.
