# Retro Trans v0.5.22

New **PS3 DLC** tab for creating translated copies of owned Z3 DLC.

Select your installed DLC folder and the matching English base ISO (or game
folder), choose a new output folder, then create the translated copy. Leave
Local patch blank to discover a compatible public bundle, or select its ZIP.
Only recognized DLC you already have is processed. Every input and output is
verified; originals, licenses, emulator installations and saves are untouched.

Install your licensed DLC normally first, then follow INSTALL.txt to back up
and replace only the generated EDAT files. This is not an automatic installer,
license downloader or source of missing DLC. Physical PS3 DLC gameplay has not
been verified. Z3 requires the exact base version declared by its DLC bundle.

When updating a PS3 base game, refresh its old installation data as instructed,
not saved games or the DLC directory. Retro Trans never deletes that data.

Includes catalog integrity checks and retains v0.5.21 RVZ support and existing
ISO, CHD, DCP, Vita and save workflows. This release updates Windows only.
macOS and Android downloads are unchanged.
