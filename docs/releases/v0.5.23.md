Retro Trans 0.5.23 adds **combined-source xdelta support** for games whose patch
needs more than one original file, including **Apathy - Gakkou de Atta Kowai
Hanashi - Kiwame**.

### Patch and update Apathy

With Apathy 0.8.1's published catalog entry, choose **Folder** in Automatic and
select the folder containing the original `kiwame.exe` and `kiwame.tpatch` from
Steam build 10331351. The app verifies both files and combines them temporarily;
you do not need to prepare the source yourself.

Already using the public 0.8.0 English executable? Browse to that executable,
choose **Latest**, and use the smaller compatible upgrade patch. The full patch
is about 162 MB; the upgrade is about 247 KB. Choose a new output filename, then
copy the verified executable into the closed game's folder as `kiwame.exe`,
keeping a backup and all saves. External development `package.nw` layouts need
migration first. See the [game instructions](https://github.com/retro-trans/Apathy-Kiwame/blob/main/docs/RETRO_TRANS_TOOLS.md).

### Verification and compatibility

- Explicit source order, exact per-file sizes and SHA-256 hashes, and a final
  combined-source hash are checked before patching.
- Missing, changed, ambiguous or symbolic-link components are rejected.
- Temporary combined files are cleaned on success, failure and cancellation.
  Original files, user saves and existing output files are never overwritten.
- Existing original and translated-file recognition, verified upgrade chains,
  DCP, Vita, RVZ, CHD, DLC and save-conversion workflows remain supported.
- Local validation: 372 tests pass with 5 skipped; native combined-source GUI
  and standalone startup/engine checks pass. Both actual Apathy patch routes
  produce the same verified executable, which passes native title/font/audio checks.

Combined-source releases use manifest schema 3 and require this version or newer.
Earlier clients reject that schema and retain their last valid catalog. Install
this Windows update before refreshing the catalog for Apathy.

Downloads include the standalone Windows EXE, a ZIP with notices/instructions,
and verified next-launch update metadata. No game files or saves are included.
