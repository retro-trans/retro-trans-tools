Fixes GitHub certificate verification on Windows while keeping HTTPS checks enabled.

### Downloads

- **Windows x64:** `Retro-Trans.exe` or `Retro-Trans-Windows.zip`.
- **macOS:** choose the Apple Silicon (`arm64`) or Intel (`x86_64`) ZIP.
- **Linux x86-64:** extract the complete tar.gz and run `Retro-Trans`.
- **Android:** install the new preview APK (Android 8+; ARM64/x86-64).

All platform builds are checked before publication. `SHA256SUMS.txt` and
`RELEASE-VALIDATION.json` contain download identities and validation results.

### Notes

Mac apps are ad-hoc signed, not notarized. Linux requires glibc 2.39+ and
X11/XWayland; Steam Deck remains unverified. Android is a preview with manual
updates, Automatic/manual xdelta and experimental DCP; desktop-only features
are listed in `README-Android.md`. Vita PKG rebuilding requires Windows;
RVZ conversion requires Windows or Linux.

For patched PS3 games, remove the related old **installation data**, keeping
**saved games**. Retro Trans never removes either automatically.
