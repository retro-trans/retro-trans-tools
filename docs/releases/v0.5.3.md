# Retro Trans 0.5.3

Historical release notes: use **0.5.4 or newer** for ZIP-only online Vita
patching. Version 0.5.3 still checked for the now-retired individual assets.
Its published binaries were not overwritten; PS3 functionality is unchanged.

Simplifies SRW Z3 physical-Vita patching with **one patch ZIP**.

## Vita rePatch

- Leave **Local patch** blank and Retro Trans automatically downloads the
  verified `SRW-Z3-v0.9.0-Vita-patches.zip` from the
  [SRW Z3 v0.9.0 release](https://github.com/retro-trans/SRW-Z3/releases/tag/v0.9.0).
  It contains the same 153 patches and metadata; the translated game build
  has not changed.
- You can also select the ZIP directly in **Local patch**. There is no need
  to extract it or download individual patches manually. Existing local JSON
  profiles remain supported.
- The workflow is unchanged: **original PCSG00264 v01.00 PKG + matching
  NoNpDrm work.bin → Create rePatch → copy to Vita**. Use a new output folder,
  an x64 Windows PC, internet and at least **6 GB free** on the output drive.
- Verifies the ZIP's published checksum and every included patch. Rejects
  missing, extra, duplicate, unsafe or corrupt files and cleans up temporary
  extraction. Correct file-picker filters are now shown for each Vita input.

See [Vita instructions](https://github.com/retro-trans/retro-trans-tools/blob/main/docs/VITA_REPATCH.md)
and [Getting work.bin](https://github.com/retro-trans/retro-trans-tools/blob/main/docs/VITA_WORK_BIN.md).
No game package or license is included or uploaded. This ZIP is a patch bundle,
not a ready-to-copy rePatch folder, Vita3K installer, or PKG-to-PKG xdelta.
Physical-Vita gameplay testing remains pending for this integration; the Vita
staff roll and ending teaser remain Japanese.

## Existing workflows

- Existing 0.5.2 clients can still download the individual patches. Those
  assets and their metadata have not been removed or replaced.
- PS3/disc patching, cached-catalog upgrade routes, CHD handling and save
  conversion remain unchanged. No cache reset is required.
- Your original PKG, work.bin, installed games, emulator setup and saves stay
  untouched. Back up saves and old overlays before copying the generated
  `rePatch/PCSG00264` to `ux0:rePatch/PCSG00264` on a compatible modified Vita.

## Downloads

- **Retro-Trans.exe:** standalone Windows x64 app; no Python installation needed.
- **Retro-Trans-Windows.zip:** the same EXE, README, and third-party notices.
- **UPDATE.json:** executable size and SHA-256 for verified automatic updates.

Existing installations check for updates at startup and install staged updates
on the next launch, preserving settings and caches. Catalog updates remain
independent of application releases.
