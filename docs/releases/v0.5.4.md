# Retro Trans 0.5.4

Fixes the ZIP-only Vita workflow. **Update from 0.5.2 or 0.5.3 before creating
the SRW Z3 rePatch folder online.**

## Vita rePatch

- Uses `SRW-Z3-v0.9.0-Vita-patches.zip` and its metadata without requiring any
  individual `.xdelta` assets on the release. Version 0.5.3 downloaded the ZIP
  but still checked for those individual files; that dependency is removed.
- The user approved retiring the 153 bare Vita assets after this update is
  verified. The ZIP contains the same patches and produces the same game files.
- Select your original **PCSG00264 v01.00 PKG**, matching NoNpDrm **work.bin**
  and a new output folder, then **Create rePatch**. Leave **Local patch** blank
  for automatic download, or select the ZIP directly without extracting it.
- ZIP checksum, exact inventory and every included patch/output hash are still
  verified. Missing or corrupt ZIP contents fail safely. No game or license is
  included in the download or uploaded by the app.

Use an x64 Windows PC, internet and at least **6 GB free** on the output drive.
See [Vita instructions](https://github.com/retro-trans/retro-trans-tools/blob/main/docs/VITA_REPATCH.md)
and [Getting work.bin](https://github.com/retro-trans/retro-trans-tools/blob/main/docs/VITA_WORK_BIN.md).
Copy the generated `rePatch/PCSG00264` to `ux0:rePatch/PCSG00264` after closing
the game and backing up saves/older overlays. Compatible rePatch and your
installed original game are required.

Physical-Vita gameplay testing remains pending for this integration. The Vita
staff roll and ending teaser remain Japanese. This is not a Vita3K installer,
a ready-to-copy game folder, or a PKG-to-PKG xdelta.

## Existing workflows

- PS3 patches and existing cached-catalog upgrade routes are unchanged. No
  cache reset is needed. CHD handling and save conversion are retained.
- The old 0.5.2 app release was withdrawn at the user's request; its source
  tag and a local recovery copy are retained. Older installed apps can update
  through the normal latest-release updater.
- Published 0.5.3 binaries are not overwritten. This fix is a new immutable
  app release; old 0.5.3 users must update for online ZIP-only Vita patching.

## Downloads

- **Retro-Trans.exe:** standalone Windows x64 app; no Python installation needed.
- **Retro-Trans-Windows.zip:** the same EXE, README, and third-party notices.
- **UPDATE.json:** executable size and SHA-256 for verified automatic updates.

Existing installations check for updates at startup and install staged updates
on the next launch, preserving settings and caches.
