# 0.5.5 Mac test-build validation

Superseded by [0.5.6](v0.5.6-macos-test-validation.md). A subsequent user report
revealed that 0.5.5 did not bundle HTTPS CA certificates. The online checks below
ran in the CI Python interpreter, not in the frozen app. Offline startup and
update checks passed, but did not establish packaged HTTPS connectivity. The
0.5.6 build adds bundled roots and a frozen-app network test with host CA paths
unavailable. Do not distribute 0.5.5 as the current Mac build.

User authorized a dedicated branch push and macOS CI test builds, not a release.
Branch: `codex/macos-feature-parity`. Compiled source: `7af3856`.
Workflow [37947388822](https://github.com/retro-trans/retro-trans-tools/actions/runs/37947388822)
passed on Apple Silicon macOS 14, Intel macOS 15, and Windows.

Each runner executed 193 tests, with three expected skips. Mac skips only the
Windows process/read-lock fixtures and opt-in live catalog test; Windows skips
the two Mac-only fixtures and opt-in live test. Shared GUI, catalog, patches,
CHD and save tests run natively, including CommonCrypto known-answer and
authenticated synthetic MX fixtures on both Macs.

Packaged apps pass native startup, xdelta startup, verified CHD round-trip,
all four tabs, whole-bundle replacement, previous-bundle preservation and the
actual detached-helper next-launch update. Both official architecture-specific
Vita3K DMGs pass verified download, read-only mounting, unmodified app copy,
portable-directory CLI startup and detach checks. Unit tests cover conversion
cancellation, metadata, ZIP overlays and cleanup. No real game/license data
was uploaded to CI.

## Limits and publication boundary

- Real PKG + work.bin conversion on Mac is **not yet verified**. The official
  CLI check is not a substitute for a user game-file test. Both reports carry
  `real_game_pkg_tested: false`.
- Existing experimental MX checkpoint/physical-console limitations remain.
  MX still reads the specified Windows PPSSPP EXE as data, without running it.
- Ad-hoc signed, not Developer ID signed/notarized; Gatekeeper approval may be
  needed. No signing credentials or provisioning accounts were changed.
- No tag, release, main merge, game patch/catalog mutation or Windows release
  replacement. Workflow artifacts expire after30 days; local copies retained.
- Any later auto-updated stable build must use a version newer than this0.5.5
  test build; do not silently replace equal-version artifacts.

Earlier runs caught macOS system-alias comparisons and platform-specific test
doubles. Those failures were corrected, not skipped. Final native fonts and
explicit minimum OS declarations are included in the verified artifacts above.
