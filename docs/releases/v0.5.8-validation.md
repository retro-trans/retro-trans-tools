# Retro Trans 0.5.8 local Windows test build

The Vita tab now selects a destination: **Vita3K PKG** or **Hardware rePatch**. Game identity, exact source revision, files and translation extras come from the selected profile. Future games with the supported native format can add profiles without adding game-specific UI code.

The complete suite ran 226 tests successfully, with four platform-specific skips. Packaged Windows health checks verified the generic Vita tab, bundled format constants and cryptography. Synthetic PKG profiles for PCSG00597 and PCSE12345 and a hardware profile for PCSE12345 passed.

The packaged app converted the Cross Ange 0.1.13 patch ZIP and original user-supplied PKG using the matching local license. It installed the resulting encrypted package into a second isolated official Vita3K filesystem and verified all 48 game files. Its complete package SHA-256 matched the independently validated standalone build. Original package and license remained unchanged. Standard Automatic recognition and both component patch outputs also passed complete-file hashes.

Full identities and evidence are in [v0.5.8-validation.json](v0.5.8-validation.json). The app is a local Windows test build and has not been pushed or published. Existing uncommitted diagnostics work was preserved. Mac PKG output, other real-game profiles, physical-Vita compatibility and gameplay remain unverified. Supported PKG formats are documented in [VITA_PKG.md](../VITA_PKG.md).
