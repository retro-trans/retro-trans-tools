# Retro Trans 0.5.9 local Windows test build

**Vita → Vita3K PKG** now accepts an original package, matching user-supplied license and new output filename. Leave **Local patch (optional)** blank to discover and download the matching translation automatically. A local ZIP/JSON remains an override. Public releases need no sign-in; private releases can use the user's existing GitHub CLI sign-in.

The complete suite ran 236 tests successfully, with four platform-specific skips. Coverage includes a second game's profile, cached downloads, newest matching original revision, mismatched originals, missing and ambiguous projects, publisher checksums, asset addresses, cancellation, stripped redirect authentication, PS3 rejection before network access, and the GUI's enabled action with a blank patch field.

The frozen Windows app passed its health check. Invoked without a local patch argument, it discovered Cross Ange PCSG00597, downloaded the private 0.1.13 release profile and patch ZIP using the existing local account, rebuilt the encrypted package, and verified all 48 files after isolated native Vita3K installation. The complete package hash matched the independently verified standalone 0.1.13 build. Original package and license remained unchanged; existing emulator setup and saves were not touched.

Full checks and binary identities are in [v0.5.9-validation.json](v0.5.9-validation.json). No app source push or release publication was requested. Gameplay and physical-Vita compatibility remain unverified. Cross Ange's existing private 0.1.13 release assets were read, not changed.
